# 정책 페이지 업데이트 검토

## 변경 범위

기존 `privacy.html` 주소를 유지하고 서비스 약관 `terms.html`, 정책 진입 `index.html`을 추가한다. ko/en/de/es/fr/it/pt별로 약관·개인정보처리방침을 제공한다. 원본은 `content/` JSON, HTML은 생성 결과다.

Google Play 앱 콘텐츠의 서비스 약관에는 `https://hyunjunyim81.github.io/vora-extension/terms.html`, 개인정보처리방침에는 기존 `https://hyunjunyim81.github.io/vora-extension/privacy.html`을 사용한다. 각 페이지에는 7개 언어 선택이 있다. 루트 주소는 한국어·영어 본문도 함께 제공한다.

## 1차 검토 실제 동작과 공개 정보

- 현재 VORA 1.1.19의 사양 및 소스에서 사진·영상·선택적 마이크·프리미엄·얼굴 AR·자동 얼굴 모자이크·MediaStore·권한·백업 설정을 확인했다.
- Play 등록정보에서 개발자 표시명 `MINJIYUN`, 문의 이메일 `mgfrind@gmail.com`, 기존 개인정보처리방침 URL을 확인했다. 과거 문서의 `mgfriend@gmail.com`과 달라 현재 스토어 주소로 통일했다.
- 기기 내 미디어·얼굴 처리와 광고·결제·ML Kit 지표·GitHub 호스팅의 외부 처리를 구분했다.
- 기존의 앱 삭제 시 사진도 즉시 삭제된다는 설명을 수정했다. 공유 저장소·외부 사본·백업·구매 기록은 별도다.
- 일회성 구매를 구독으로 표현하지 않았으며 존재하지 않는 구매 복원 버튼·계정 삭제 기능·서버 얼굴 인증을 추가하지 않았다.
- 실제 판매자 법적 이름·주소·전화번호를 추정하지 않았다. 표시명과 Play 등록정보를 참조하며 Console의 판매자 선언을 대신 제출하지 않는다.

## 2차 검토 번역과 권리 조항

- 7개 언어 모두 약관 10개 조항, 개인정보처리방침 11개 조항이며 ID·순서·단락 수가 같다.
- 시행일, 앱 이름, 표시 개발자명, 문의 주소, 일회성 구매, 기기 내 얼굴 처리, 삭제와 백업, SDK 통신을 언어 간 대조했다.
- 환불·청약철회·디지털 콘텐츠 하자에 관한 법정 권리를 일괄 배제하지 않는다. 앱 사용만으로 청약철회권을 포기한 것으로 쓰지 않았다.
- 영어 또는 한국어가 무조건 우선한다는 조항, 전면 면책, 확인하지 않은 관할 법원·최저 연령·보존기간을 추가하지 않았다.
- 독일어 얼굴 검출 표현을 신원 인식과 혼동하지 않도록 수정했다. 스페인어·이탈리아어·포르투갈어의 원격 삭제 불가 문장은 개발자가 주어임을 명확히 했다.
- 관련 법령이 적용될 때의 계약 이행·문의/보안의 정당한 이익·법적 의무·필요한 동의 근거를 같은 조항에 설명했다. 권한 허용을 광고 등 모든 처리에 대한 포괄 동의로 쓰지 않았다.

## 3차 검토 링크와 실제 표시

- 생성 단계에서 7개 언어의 조항 ID·순서·필수 문구·단락 수를 검사했다.
- HTML 17개의 내부 파일 링크·앵커·중복 ID·문서 언어·단일 H1·스크립트 부재를 확인했다.
- 실제 Chromium에서 언어별 14개와 루트 2개를 데스크톱 1280×900 / 모바일 390×844로 확인했다. 총32개 페이지/화면 조합에서 가로 넘침과 페이지 오류는0이다.
- 루트의 언어 전환 14개와 진입 페이지의 언어별 링크14개를 확인했다. 키보드 Tab으로 링크에 접근했다.
- 한국어 개인정보, 영어 약관, 독일어 개인정보, 프랑스어 약관의 모바일 화면과 진입 화면을 확인했다. 스크린샷은 로컬 `/tmp/vora-legal-preview/` 검토용이다.
- 본문은 JavaScript·로그인·외부 폰트·자동 번역 없이 읽을 수 있다. 외부 서비스의 설정·지원 링크는 해당 제공자의 정책을 따른다.

이 검토는 구현 사실·번역 정합성·페이지 동작의 검토다. 모든 국가에서의 법률 적합성 인증이나 Play 심사 통과 기록은 아니다.
