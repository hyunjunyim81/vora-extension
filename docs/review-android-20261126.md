# Android 무료 AR 계약과 공개 정책 정정

사용자 요청으로 Android 수정 후 Google Play 배포를 진행한다. 실제 Android 사양의 무료 AR 선택과 프리미엄 광고 제거/필터 세부 조절 혜택을 정책7언어에 반영한다.

변경 범위는 terms의service/premium과 privacy의settings 단락이다. AR을 실험실 스위치·구매 조건으로 설명하지 않고 선택한 효과 설정의 보존으로 설명한다. 기존 권한/기기 지원·일회성 구매·Google Play 복원·개인정보 처리·법정 권리는 유지한다. 다른 조항과 iOS 정책은 변경하지 않는다. 7개 JSON 원본을 고치고 기존 렌더 도구로 HTML을 생성한다.

검증 기준:7언어 조항 ID/단락 수·구매 혜택·무료 AR 의미·링크와 마크업·모바일 가로 넘침·생성 재현성을 확인한다. 세 관점의 실제 검토 결과와 GitHub Pages 공개 응답을 완료 후 기록한다. 푸시 성공을 공개 갱신으로 단정하지 않는다.

## 실제3회 검토

1. 기능/출시 경계: Android의 AR 선택은 구매 없이 가능하며 프리미엄은 광고 제거/필터 세부 조절이다. 서비스·구매 조항의 AR 프리미엄 조건과 로컬 설정의 실험실 스위치를21개 단락에서 고쳤다. 현재 프로덕션이1.1.20(24)이고 신규 비공개 버전이1.1.21(25)임을 확인해 무료 AR 설명에는Android1.1.21 기준을 명시했다. 이전 버전 동작을 새 동작으로 단정하는 문제를 방지했다.
2. 번역/구조:7언어가 같은 무료 범위·일회성 구매·복원·기기 지원 조건을 설명하는지 대조했다. 조항 ID와 단락 수를 유지하고 다른 조항/리소스 링크·iOS 정책 원본과 출력은 변경하지 않았다. 시행/수정일과 HTML datetime을2026-11-26으로 맞췄다.
3. 표시/재현:모바일390×844의16개 Android 정책 페이지와 데스크톱1280×844의루트2개,총18조합에서 가로 넘침/실행 스크립트 없음이 통과했다. 원본 대비 변경 조항이의도한21개뿐인지 검사하고 재생성한16개 Android HTML의해시가 같은지 확인했다. git diff --check 통과. 공개응답은푸시후별도로대조한다.
