# VORA 공개 정책 페이지

VORA의 Google Play 등록정보와 앱 콘텐츠 선언에서 사용하는 정적 정책 페이지다. 로그인·추적 스크립트 없이 한국어·영어·독일어·스페인어·프랑스어·이탈리아어·포르투갈어를 제공한다.

| 페이지 | 공개 주소 | 용도 |
| --- | --- | --- |
| 정책 안내 | https://hyunjunyim81.github.io/vora-extension/ | 약관과 개인정보처리방침 진입 |
| 서비스 이용약관 | https://hyunjunyim81.github.io/vora-extension/terms.html | 앱 콘텐츠의 서비스 약관 URL |
| 개인정보처리방침 | https://hyunjunyim81.github.io/vora-extension/privacy.html | 기존 스토어 개인정보처리방침 URL 유지 |

각 언어는 `/ko/`, `/en/`, `/de/`, `/es/`, `/fr/`, `/it/`, `/pt/` 아래에 같은 파일명으로 제공한다. 기존 루트 주소는 한국어·영어 본문과 모든 언어 링크를 유지한다. 로그인·브라우저 자동 번역·JavaScript 실행 없이 전문을 읽을 수 있다.

## 편집과 생성

편집 원본은 `content/<언어>.json`이다. 모든 번역은 같은 조항 ID와 단락 수를 사용한다. 기능이나 권리 조항을 바꾸면 7개 번역을 함께 검토한다. 영어 우선 등 사용자의 법정 권리를 제한하는 언어 우선 조항을 추가하지 않는다.

`python3 tools/render_policies.py`로 HTML을 생성한다. 생성된 HTML만 직접 수정하지 않는다. 렌더 도구는 Python 표준 라이브러리만 사용한다.

## 콘텐츠 사양

- 앱 기능·데이터 처리는 개발 저장소의 `Vora/docs/current/` 및 실제 구현과 대조한다.
- 서비스 운영자 표시는 공개 Play 등록정보의 개발자명 MINJIYUN을 참조한다. 문의 이메일은 같은 등록정보의 `mgfrind@gmail.com`이다. 확인하지 않은 법적 이름·주소·전화번호를 만들지 않는다.
- 이용약관은 기능 범위, 일회성 프리미엄 구매와 복원, Google Play 환불 및 법정 권리, 미디어 권리, 지원·변경·종료를 구분한다. 앱 사용만으로 청약철회권을 자동 포기한 것으로 쓰지 않는다.
- 개인정보처리방침은 사진·영상·음성, 기기 내 AR/모자이크 얼굴 처리, 광고·동의·구매 SDK, 앱 설정·백업, 공유·삭제를 설명한다. 광고 SDK가 있는데 모든 정보가 절대 외부로 전송되지 않는다고 쓰지 않는다.
- 앱 삭제 후 MediaStore 사진·영상은 남을 수 있다. 갤러리 삭제, 외부 공유, OS/사진 서비스 백업과 앱 내부 데이터 삭제를 구분한다.
- 구매 데이터 보존기간·서버 위치·회사 정보·특정 연령 등 확인하지 않은 수치를 임의로 확정하지 않는다.
- HTML은 모바일에서도 읽기 쉽고 키보드로 링크를 사용할 수 있어야 한다. 외부 폰트·분석 도구·로그인·새 수집 동작을 추가하지 않는다.

## 변경과 게시

통합 브랜치는 `develop`이다. 작업 브랜치에서 사양을 먼저 수정하고 HTML을 업데이트한다. 코드/기능 사실, 한국어·영문 정합성, 링크·마크업·모바일 표시의 세 관점에서 검토한 뒤 커밋 → `develop` 머지 → 작업 브랜치 삭제 → 푸시 순서로 진행한다.

기존 GitHub Pages의 게시 설정을 유지한다. 푸시 성공과 공개 페이지 갱신은 별도로 확인한다. 이 저장소 변경은 Play Console의 판매자 선언·데이터 보안 답변을 자동 제출하지 않는다.

정책 초안과 실제 운영이 다르면 먼저 사실을 확인해 수정한다. 기능의 변경 예정 상태를 이미 출시된 기능이라고 단정하지 않는다.
